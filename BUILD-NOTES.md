Build notes for the One Line, One Chill entry.

The bounty asks for one sentence of horror under two hundred characters, judged on how frightening, vivid, original, and well crafted it is. The obvious field is crowded with mirrors, dolls, basements, and gore, so this entry deliberately avoids all of them.

The chosen line uses a doorbell camera, a mundane device readers already trust, and builds the scare from a single contradiction: the camera recorded the narrator leaving for work this morning, while the narrator has not left the house in three days. Nothing is named or explained, so the dread outlasts the sentence. The final words carry the twist.

The program is a small deterministic Python script. It holds the line as a fixed string and writes it exactly as written to the output file, with no trailing newline, so the file holds the entry and nothing else. The entry was checked for length and single-sentence shape before committing. The repository holds the entrypoint at its root, a linked-badge readme, and an MIT license carrying the SPDX identifier line.
